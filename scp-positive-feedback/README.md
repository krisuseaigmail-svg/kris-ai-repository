# SCP 正向反馈模型

交互式学习页：把产业组织经典框架 **Structure（结构）→ Conduct（行为）→ Performance（绩效）** 补上 **P → S** 回灌，形成可推演的正向反馈飞轮。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

## 你可以做什么

- 切换「电商平台 / 内容社区 / SaaS」三类场景
- 调节进入壁垒、差异化、再投入强度
- 「推动一圈」或「自动飞轮」，观察绩效如何改写结构动量

## 构建

```bash
npm run build
```
